# Nikhil Pathrabe — Portfolio

A responsive React/Vite portfolio for Nikhil Pathrabe, an AI Engineer working across GenAI, RAG, voice agents, and cloud delivery.

## Run locally

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Deploy to Vercel

This project includes the requested `vercel.json` configuration. Import the GitHub repository into Vercel and keep the default project settings, or use:

- Build command: `pnpm build`
- Output directory: `dist/public`
- Install command: `pnpm install`
- Framework: `Vite`

No API keys or backend endpoints are required.
